# Thai PUA Starter 🇹🇭

ชุดเริ่มต้นสำหรับผู้ฝึกทำม็อดภาษาไทย: แปลง **ข้อความไทยที่ตรวจแก้แล้ว → PUA** พร้อมฟอนต์ต้นทางที่ตรงกับ Mapping และตัวอย่างเปิดดูในเบราว์เซอร์ ใช้งานออฟไลน์ด้วย Python 3.10+ ไม่ต้องติดตั้งไลบรารีเพิ่ม

**ชุดนี้ไม่ใช่ตัวแก้สระลอยอัตโนมัติสำหรับทุกเกม และยังไม่ใช่ตัวติดตั้งภาษาไทยของ Revelations**

## เริ่มทดลองบน Windows

1. กด **Code → Download ZIP** แล้วแตกไฟล์ทั้งหมด
2. ติดตั้ง Python 3.10 ขึ้นไป เปิด Terminal ในโฟลเดอร์ที่แตก
3. รันตัวอย่าง:

```powershell
python thai_pua.py examples/thai.txt -o examples/thai.pua.txt --preview preview.html
```

เปิด `preview.html` ในเบราว์เซอร์ จะเห็นข้อความไทยต้นฉบับเทียบกับข้อความ PUA ที่ใช้ฟอนต์ใน `assets/` ไม่ต้องติดตั้งฟอนต์ลง Windows หากสั่งซ้ำให้ใช้ชื่อผลลัพธ์ใหม่หรือลบเฉพาะผลลัพธ์ทดลองเดิมเอง โปรแกรมจะไม่ทับไฟล์ที่มีอยู่

ลองไฟล์ของตนเอง:

```powershell
python thai_pua.py my_thai.txt -o my_thai_pua.txt
python -m unittest discover -s tests -v
```

รับเฉพาะ `.txt` ที่เป็น UTF-8 หรือ UTF-8 BOM รักษา BOM, CRLF/LF/CR และจำนวนบรรทัด ไม่แก้ต้นฉบับ ไม่แปลงไฟล์เกมโดยตรง **อย่าส่ง CSV/JSON ทั้งไฟล์มาแปลง** ให้แยกเฉพาะข้อความแปลตามรูปแบบ importer ของเกมก่อน IDs, keys และข้อมูลโครงสร้างต้องไม่ถูกแปลง

## ทำไมแปลงข้อความอย่างเดียวอาจยังไม่หาย

PUA คือการใช้รหัสตัวอักษรส่วนตัวอ้างรูปพยัญชนะ+สระ+วรรณยุกต์ที่เตรียมไว้ร่วมกัน ฟอนต์ต้องมีรูปที่ตรงกับ Mapping ทุกตัว ฟอนต์ธรรมดาจะอ่านผลลัพธ์เป็นช่องสี่เหลี่ยมหรืออักษรแปลก ๆ ซึ่งไม่ใช่การเข้ารหัสเสีย

เกมยังต้องมี glyph IDs, atlas, advance, baseline, offsets และพื้นที่แสดงผลที่เหมาะสม สระล่างที่ขาดอาจต้องแก้ขอบ glyph หรือพื้นที่ตัดภาพในระบบฟอนต์ของเกมด้วย ตัวอย่าง HTML ยืนยันได้เฉพาะการจับคู่ข้อความกับ **ฟอนต์ต้นทาง** ไม่ได้ยืนยัน native font หรือผลในเกม

## สำหรับ Assassin’s Creed Revelations

แนวทางนี้มาจากงาน Steam PC ที่ใช้ Forge v25 / Scimitar และ native `Fire_Font_Descriptor` คู่กับ BC3 atlas ส่วน TTF ที่ให้เป็น **วัตถุดิบทำฟอนต์** นำ TTF ไปวางในเกมอย่างเดียวไม่ได้

ลำดับงานคือ สำรองไฟล์ → export ข้อความ → แปลและตรวจในรูปไทยปกติ → แปลง PUA → สร้าง/ปรับ native font ให้ครอบคลุม glyph ที่ใช้ → import ข้อความกลับ → ตรวจ export ซ้ำ → ทดสอบเมนู/ซับในเกม ดู [คู่มือฟอนต์](docs/FONT_WORKFLOW_TH.md)

ต้องตรวจ build และรูปแบบของเกมที่ใช้อยู่ก่อน เกมอื่นในตระกูลเดียวกันก็ไม่ควรใช้ offsets หรือ native assets แทนกัน ชุดนี้ไม่มี Forge/DATA packer และไม่มีไฟล์เกมให้ดาวน์โหลด

## ตัวตรวจและข้อจำกัด

- จับลำดับที่ยาวที่สุดก่อน เช่น พยัญชนะ+สระ+วรรณยุกต์ ไม่ตัดจับเฉพาะพยัญชนะก่อน
- Normalize NFC และรูปแยกของสระอำก่อน Mapping จึงไม่ใช่การแปลงที่ย้อนกลับได้แบบ byte-for-byte ให้เก็บฉบับไทยอ่านได้เสมอ
- ปฏิเสธอักขระนอก Char.txt, combining marks ที่ยังไม่ถูกแปลง, UTF-8 เสีย, NUL และ PUA ในต้นฉบับ เพื่อป้องกันแปลงซ้ำ
- คงข้อความ ASCII เช่น `<br>`, `%s`, `{name}` ตามเดิม แต่ไม่ใช่ตัวตรวจไวยากรณ์ placeholder ของทุกเกม
- คำไทยที่ผิดสะกด/วรรณยุกต์ซ้ำควรแก้ต้นฉบับ ไม่เพิ่ม glyph เพื่อซ่อนข้อผิดพลาด
- แปลง Mapping ครบ 2,208 ลำดับได้ใน TTF ที่ให้ แต่ native atlas ของเกมอาจมีเพียงบางส่วน ต้องตรวจ glyph ที่ใช้จริงก่อน pack
- ไม่แตะไฟล์เกม ไม่ติดตั้งฟอนต์อัตโนมัติ ไม่เรียกเครือข่าย และไม่แก้ THub/TStudio/TRun
